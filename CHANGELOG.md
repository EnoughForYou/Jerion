## [Unreleased]

### Added
- **Audit Hardening & Cross-Platform CI Fix**:
  - **Cross-Platform Preflight Checksum Portability**: Updated `TestTrustedPlatformToolsHashes` and `TestStrictChecksumMatching` in `internal/preflight/preflight_test.go` to validate `DefaultPlatformToolsSHA256()` dynamically against host environment `runtime.GOOS`, and added table-driven test cases covering Windows, Darwin (macOS), and Linux official catalogs independently, resolving Ubuntu CI runner check failures.
  - **Device Unauthorized Error Propagation**: Enforced proper error forwarding from `getTargetSerial()` in `RemediateCreatePlan` and `RemediateExecute`. Ensured `DeviceUnauthorized` wire error is returned directly rather than masked as `DeviceOffline` when RSA debugging prompt has not yet been accepted by the user on the device.
  - **Updated System App Detection & Remediation Safety**: Replaced fragile active APK path substring heuristics with Package Manager metadata checks (`isSystemPackage` in `app.go` and `IsSystemPackage` in `internal/inventory/inventory.go`) leveraging `pm list packages -s`, dumpsys `SYSTEM`/`UPDATED_SYSTEM_APP` flags, and mount points. Properly categorized updated system apps (e.g. apps updated via Google Play with base APK in `/data/app/`) as system apps, assigning safe `pm uninstall --user 0` without requiring destructive local APK backups.
  - **Flag Token Boundary Matching & Layering Discipline**: Enforced exact flag token boundary matching in `ParseDumpsysPackage` to eliminate false positive system classifications on user apps containing flags like `REQUIRED_FOR_SYSTEM_USER`. Refactored `app.go:isSystemPackage` into a thin delegation to `internal/inventory.Service`, sanitized package names with `adb.ValidatePackageName`, standardized canonical partition mount points (`isSystemMountPath`), and expanded table-driven test coverage across edge cases.
  - **ScanQuick Terminal State Recognition**: Updated synchronous quick scan polling in `app.go:ScanQuick` to recognize all terminal statuses (`completed`, `partial`, `failed`, `cancelled`), preventing 60-second timeouts when scans terminate with failed, cancelled, or partial states.
- **Fidelity Hardening Round 5 (Atomic Reservation, Strict DeviceID, Audit Accuracy, Partial Scan Truth & AppOps Parser)**:
  - **Strict DeviceID Binding in Scan Cache**: Changed scan result cache check in `RemediateCreatePlan` to enforce `res.DeviceID == expectedDevID` strictly, rejecting unassigned or empty DeviceID cached scans from generating remediation plans for active devices, with defensive nil-guard checks.
  - **Atomic Batch Pre-validation & Cache Reservation**: Locked batch pre-validation and action extraction under exclusive mutex `a.mu.Lock()` in `RemediateExecute`. Pre-validated duplicate action IDs in caller requests, verified device serial consistency, and atomically extracted canonical actions to local memory while purging all reserved action IDs from backend cache before executing actions on the physical device. Initialized all log and report response slices to non-nil to ensure valid empty JSON arrays.
  - **Independent Audit Persistence UI & Execution Status Accuracy**: Separated device action execution status (`status === "success"`) from audit log persistence status (`auditSaved`, `auditError`) in `RemediateView.tsx`. Calculated execution feedback banners strictly by successful device operations, warned independently when SQLite audit persistence fails (even when database store is unconfigured or nil), and displayed distinct badges and diagnostic error messages in the history log with robust modal closure on errors.
  - **Partial Scan Verdict Honesty & Filter Empty States**: Configured both live scan conversion (`convertEngineScanResult`) and database scan record conversion (`convertStoreScanRecord`) to assign `Summary.Verdict = "review"` for partial scans (`res.Partial == true`) that have zero threat findings, preventing incomplete scans from falsely rendering as "clean" across all views and reloads. In frontend `ScanView.tsx`, prioritized terminal and partial-empty alerts over filter empty states to prevent incomplete scans from being masked.
  - **Defensive AppOps Overlay Parsing & Fallback**: Updated `ParseAppOpsOverlay` and `ParseSingleAppOpOverlay` in `internal/inventory/parser.go` to return `(allowed bool, recognized bool)`, distinguishing valid denied responses (`No operations.`, `deny`, `ignore`, `default`) from unparseable shell outputs (which correctly trigger `overlay_status_unknown`). Added package header token splitting for bracketed UIDs and implemented fallback from `cmd appops` to `appops` when output format is unrecognized.
- **Fidelity Hardening Round 4 (Fail-Closed Device Binding, Pre-validation, Scan Verdict Honesty & Downloader Regression Test)**:
  - **Fail-Closed Remediation Device Binding**: Enforced strict fail-closed requirements in `RemediateCreatePlan` and `RemediateExecute`, returning `DeviceOffline` error immediately if no trusted device is actively connected. Scoped cached scan finding lookups and SQLite database finding queries exclusively to the active device serial, preventing remediation plans from being generated for disconnected or cross-device targets.
  - **Pre-validation & Canonical Action DTO Construction**: Implemented a comprehensive fail-closed pre-validation loop in `RemediateExecute` that validates the existence of every action ID and its device serial match before executing any commands on the device. Reconstructed result action entries from trusted backend cached actions rather than caller-provided DTOs, eliminating client parameter tampering risks and preserving partial results if a command fails mid-batch.
  - **Scan Verdict Honesty & Transparent Failure UI**: Fixed failed and cancelled scans in `app.go:ScanStart` to assign `Summary.Verdict = "review"` instead of `"clean"`. Updated frontend `ScanView.tsx` to conditionally display verdicts only for completed or partial scans, and render an explicit warning alert card on failed or cancelled scans explaining that threat analysis was not completed.
  - **Runtime Three-State Truth (Overlay, Device Admin & Battery Whitelist)**: Assigned `overlay_status_unknown` flag when AppOps query fails for apps requesting `SYSTEM_ALERT_WINDOW`. Added automatic fallback to `dpm list-owners` when `dumpsys device_policy` reports zero admins, assigning `device_admin_unknown` if neither command succeeds. Treated empty or unparseable `dumpsys deviceidle whitelist` output as unknown (`battery_status_unknown`), ensuring unqueried apps are not falsely marked as battery-optimized.
  - **Audit Persistence Reporting**: Captured and surfaced `m.store.LogAction` errors through optional `auditSaved: *bool` and `auditError: *string` fields on `ActionLogEntry` across Go backend structs, TypeScript bridge schema, and Wails models, decoupling device execution success from audit persistence errors.
  - **End-to-End Downloader Checksum Regression Test**: Added `NewDownloaderWithURL` and an end-to-end `httptest.Server` unit test in `internal/preflight/preflight_test.go` verifying that downloaded archives with mismatched SHA-256 digests are immediately rejected and temporary files purged before extraction.
- **Fidelity Hardening Round 3 (Device Binding, Structured Failure Reporting, AppOps & Runtime Truth)**:
  - **Remediation Plan Device Binding & Anti-Replay**: Locked remediation actions and plans to the device serial (`DeviceSerial`) where they were created; rejected cross-device execution with `wireError("DeviceMismatch")`. Enforced single-use execution by deleting actions from backend cache immediately upon processing, and invalidated cached actions and scan results whenever the active device changes or disconnects.
  - **Structured Remediation Failure Reporting**: Updated `remediate.Execute` and `app.go:RemediateExecute` to construct and return structured `contract.ActionLogEntry` with `Status: "failed"` and detailed error messages whenever guardrail blocks or APK backup errors occur, persisting failed actions to SQLite `action_log` and preventing silent omissions in the frontend.
  - **AppOps Overlay Permission Verification**: Evaluated overlay permissions (`SYSTEM_ALERT_WINDOW`) strictly via active AppOps (`dumpsys appops` and `appops get`), eliminating false positive/negative inferences from static `dumpsys package` install permissions.
  - **Active Device Admin Detection**: Extracted all enabled device administrators from `dumpsys device_policy` ("Enabled Device Admins") and `dpm list-owners` with full component regex parsing (`(?:admin=)?([a-zA-Z0-9_.]+)/`), capturing active admins accurately across Android versions.
  - **Battery Optimization Honesty**: Handled failed battery whitelist queries by explicitly assigning `battery_status_unknown` flag and avoiding false claims that unqueried applications are optimized.
  - **Unified Canonical Scan Evidence Conversion**: Extracted shared `mapEvidenceType` function unifying evidence source mapping (`permission`, `hash`, `class_prefix`, `log`, `setting`, `manifest`) across live engine results (`convertEngineScanResult`) and persisted database findings (`convertStoreFinding`).
  - **Terminal Scan Failure Events**: Emitted terminal `scan:done` events with status `failed` or `cancelled` and `scan:failed` error messages whenever scan engine or storage operations fail, preventing UI scan progress from hanging indefinitely.
  - **Strict Checksum Verification**: Enforced exact SHA-256 matching for pinned Google Platform-Tools r37.0.1 downloads in `internal/preflight/downloader.go`, rejecting fallback to older catalog versions when an explicit expected digest is specified.
- **Fidelity Hardening & Forensic Integrity (Round 2)**:
  - **ADB Distribution & Official Checksum Verification**: Pinned official platform-tools download to Google Platform-Tools r37.0.1 (`platform-tools_r37.0.1-win.zip`) with verified SHA-256 integrity catalogs across Windows (`45f4d631...`), macOS (`ee39ad59...`), and Linux (`d230f138...`).
  - **Remediation Boundary Security & Target Sanitization**: Implemented regex-based permission cleaning stripping evidence prefixes (`Declared/Requested:`) preventing validation errors, enforced mandatory non-empty target validation on `revoke_permission` and `clear_appop` rejecting bypasses with `InvalidAction`, and strictly validated that executed remediation actions originate from backend-verified plans.
  - **Runtime Metadata Fidelity**: Evaluated overlay permissions strictly from granted permissions (`GrantedPermissions`), queried active accessibility services from system settings, active device admins from device policy manager, and battery optimization whitelist status from `deviceidle`, with conditional battery UI display avoiding misleading `0%` indications.
  - **Scan Statistics Persistence & Error Handling**: Added SQLite migration v2 introducing `total_apps` column to `scan_results`, ensuring clean scans with zero findings accurately retain the count of apps scanned. Handled scan database persistence errors explicitly and scoped finding IDs to unique scan sessions.
  - **Strict Rule Engine Decoding**: Integrated `yaml.NewDecoder` with `KnownFields(true)` across all detection rule packs, strictly rejecting unrecognized or misspelled YAML attributes.
